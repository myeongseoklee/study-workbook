# 06. 왜 직접 만드는가 — 온프레미스가 만드는 시장

## 학습 목표

"코덱스와 클로드 코드가 있는 세상에서 직접 만든 에이전트가 팔리는가"라는 질문에 근거로 답한다. 온프레미스라는 제약이 왜 기존 제품을 통째로 무력화하는지, 그래서 어떤 고객군이 존재하는지 안다.

## 선수 지식

- 1~4장: 세션·컨텍스트·컴팩션을 직접 구현해야 하는 이유 (난이도의 실체)
- ep01의 로컬 LLM 하한선(약 200B, Q5 이상) — 사내 모델로 갈 때의 제약

## 핵심 원리 (WHY) — 목적의식 없이 만들면 취미다

강의는 먼저 목적을 캐묻는다.

> **"바이브 코딩 에이전트 왜 만들어요? 취미? 토큰 버리기? 이런 거 아니라면 뭘로 해야 돼?"** `[48:30–49:00]`

그리고 자기 답을 내놓는다. **납품이다.**

여기서 당연한 반박이 나온다.

> **"코덱스와 클로드 코드가 있는 세상에서 손수 만든 에이전트를 납품?"** `[49:00]`

강의의 답은 "된다"이고, 이유는 하나다.

> **온프레미스 때문이다.** `[49:30]`

## 필수 지식 (HOW) — 온프레미스가 무력화하는 것들

기존 제품이 온프레미스 환경에서 왜 안 되는지를 항목별로 본다. 각 항목이 그대로 개발 과제가 된다.

| 제약 | 무엇이 깨지는가 |
|---|---|
| **웹 검색 불가** | 에이전트의 기본 도구가 작동하지 않는다. 이것부터 대체 수단이 필요하다 (→ 8장의 벡터DB 웹검색) |
| **모델도 사내** | 외부 API를 못 쓰므로 사내 LLM을 붙여야 하고, 모델 성능 하한 문제가 따라온다 |
| **보안 프로그램** | 파수 같은 문서보안·파일 암호화 툴이 깔려 있어 프로그램이 정상 동작하지 않는다 |

> **"일반 양키나 중국계에서 만든, 자유로운 영혼을 가진 바이브 코딩 에이전트가 안 통한다. 그래서 사야 한다. 그래서 이걸 납품해주길 원한다."** `[50:30]`

### 기업이 사는 이유 — 코어는 이미 상품화됐다

강의가 짚는 중요한 인식이 있다.

> **기업들도 안다. 코딩 에이전트 자체는 큰 기술적 격차를 일으키지 않는다.** "그게 그거"라고 본다. 여러분도 오픈코드에 클로드 API를 물려 쓴다. 기술이 다 비슷하니 거기서 거기라고 생각한다. `[50:30]`

즉 **차별화 지점이 에이전트 코어가 아니다.** 팔리는 이유는 그 주변 — 온프레미스 대응, 조직 관리, 가드레일, 모델 라우팅이다.

> **"코덱스나 이런 것들은 다 이거 지원 안 한다. 딱 보기에도 지원 안 해줄 것 같이 생겼다. 그래서 이런 것 때문에 팔린다. 여러분이 이걸 다 만들 수 있으면 팔린다."** `[57:30]`

이 판단은 제품 전략으로 바로 번역된다. **코어 루프를 남보다 잘 만들려고 경쟁하는 게 아니라, 남이 대응하지 않는 환경 제약을 대응하는 것이 상품성이다.**

## 필수 지식 (HOW) — 고객군

강의가 명시한 대상이다.

- 금융권
- 증권사
- 제조사 — "의외로 수많은 제조사들"
- 공장

한마디로 **산업용**이다. 산업용 에이전트는 온프레미스 요구가 매우 많다.

> 유통 경로는 직판이 아니다. **"파트너만 잘 걸리면 팔린다."** 아는 지인도 계속 팔고 있다고 언급한다. `[58:00]`

## 이 지식이 판단에 쓰이는 자리

- **제품 범위를 정할 때**: 코어(세션·컨텍스트·컴팩션)는 "경쟁력"이 아니라 "입장권"이다. 차별화 예산은 7~9장의 항목들에 배분한다.
- **기술 선택을 할 때**: "인터넷이 없다"를 기본 가정으로 두면 선택이 달라진다. 웹검색·모델·패키지 설치·시간 동기화가 전부 재설계 대상이다.
- **영업·파트너십을 검토할 때**: 고객군이 금융·증권·제조·공장이면 도입 절차에 보안 심사가 들어간다. 이것이 8장의 설치 환경 선택(도커 vs 네이티브)을 좌우한다.

### ⚠️ 암기 필수

- [ ] **직접 만드는 유일한 사업적 근거 = 온프레미스.** 취미·토큰 소모가 아니라면 이것이다.
- [ ] **온프레미스가 깨는 것 셋: 웹 검색 / 외부 모델 / 보안 프로그램과의 공존.** 각각이 개발 과제로 직결된다.
- [ ] **에이전트 코어는 차별화 지점이 아니다** — 기업도 "그게 그거"로 본다. 팔리는 이유는 조직 관리·가드레일·모델 라우팅·온프레미스 대응이다.
- [ ] **고객군 = 금융권·증권사·제조사·공장 (산업용).** 온프레미스 요구가 집중되는 곳.
