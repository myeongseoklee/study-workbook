# 04. 모델 라우팅 — 계획표 3번이 축을 바꿔 내려앉았다

## 학습 목표

계획표의 **개인별** 할당정책이 왜 **조직별**로 구현됐는지, 그 차이가 무엇을 남겼는지 안다. 프리셋이라는 등록 단위가 왜 필요한지, 파라미터를 누가 소유해야 통제가 유지되는지 설명할 수 있다.

## 선수 지식

- 01장: 계획표 3번의 대조 결과(변경 + 축소)
- 03장: 조직별 통제가 위임 구조 위에 얹힌다는 점
- 1강 6장: 로컬 LLM의 크기·양자화 하한 — 여기 등록되는 것이 그 모델들이다

## 핵심 원리 (WHY) — 두 개의 축이 있고, 하나만 만들었다

계획표는 이렇게 적혀 있다.

```
3. 모델라우터 — 에이전트가 사용할 모델의 개인별 할당정책
   - 로컬llm서비스와 외부 모델 서비스 결합 및 개인별 할당량에 따른 자동 전환정책 등
```

3강이 만든 것은 조직별 할당이다. 이건 축소가 아니라 **다른 축**이다.

| | 개인별 (계획) | 조직별 (구현) |
|---|---|---|
| 결정 기준 | 그 사람의 사용량·역할 | 소속 조직 |
| 필요한 것 | 사용량 집계, 소진 감지, 대체 순위 | 조직 트리, 상속 규칙 |
| 해결하는 문제 | **토큰 예산** | **접근 권한** |
| 2강에서의 위치 | "모델 라우터의 핵심 요구" (7장) | 인가 대상의 하나 (9장) |

즉 3강은 **권한 축을 먼저 만들고 예산 축을 접었다.** 접힌 쪽이 2강에서 핵심이라 불렀던 것 — 엔터프라이즈 할당 토큰이 소진되면 사내 LLM으로 무중단 전환 — 이라는 점을 기억해야 한다.

왜 이 순서가 합리적인가. 권한 축은 조직 트리(3장)가 이미 필요해서 만들어졌으므로 **추가 비용이 작다**. 예산 축은 사용량 집계 파이프라인이 새로 필요하고, 그것은 에이전트가 실제로 토큰을 쓰기 시작한 뒤에야 의미가 있다 — 그리고 에이전트는 다음 회차다.

**자기 구현에서 남겨야 할 여지**: 모델 결정을 계정에 미리 박지 말고 **호출 시점에 해석**하도록 둔다. 그러면 나중에 "할당량을 보고 다른 프리셋으로 떨어뜨리는" 판단을 그 해석 지점에 끼울 수 있다.

## 필수 지식 (HOW) — ① 모델은 코드가 아니라 데이터로 등록된다

사내 추론 서버는 회사마다 다르고 늘고 줄어든다. 목록을 코드에 두면 모델 추가가 곧 배포다. 그래서 관리 화면에서 등록하는 데이터로 만든다.

계층은 셋이다.

```
엔드포인트 (lmstudio · vllm · 외부 유료 API)
   ├─ API 형식 (OpenAI Chat Completions 등) + 인증 헤더
   └─ 모델
        └─ 프리셋 = 모델 식별자 + 샘플링 파라미터 조합
```

엔드포인트를 저장하면 모델 목록을 자동으로 끌어올 수 있다.

> **모델스 프로토콜 때리면** 모델스 프로토콜로 가져와야 되잖아.

OpenAI 호환 서버의 `/v1/models`다. 표준이라 **엔드포인트 종류를 몰라도 목록을 받는다**. 실패하면 수동 추가로 떨어진다 — 자동 조회는 편의이므로 그것이 막혀도 등록이 막히면 안 된다.

계획표의 "로컬 llm 서비스와 외부 모델 서비스 결합"이 이 구조로 충족된다. 엔드포인트를 여러 개 등록할 수 있으면 사내 LM Studio와 유료 API가 같은 목록에 들어온다.

## 필수 지식 (HOW) — ② 등록 화면이 결정 목록이다

![모델 추가 — 컨텍스트·샘플링·모달리티 18:03](assets/frames/t00-18-03.jpg)

**등록 화면의 필드 하나하나가 결정 하나다.** 캡처는 증거고, 아래 표는 각 필드가 무엇을 정하는지까지 옮긴 것이다.

| 필드 | 값 | 무엇을 정하나 |
|---|---|---|
| 모델 식별자 | `gemma4 31b` | 추론 서버가 아는 이름 |
| 컨텍스트 크기 | `262000` | 이 프리셋이 쓸 컨텍스트 = **VRAM 비용** (1강 5장) |
| 템퍼러처 | 코딩엔 0.4 | 낮으면 결정적 |
| min_p / top_p / top_k | 0 / 0.95 / 50 | 후보 분포 |
| repeat_penalty | 기본 없음 | **리즈닝 루프에 빠질 때** 주는 처방 |
| 리즈닝 | 체크박스 | 켜면 좋을 듯하나 **루프에 자주 빠져 끄는 경우도 있다** |
| 지원 모달리티 | 텍스트/이미지/사운드/비디오 | 아래 참조 |

강의가 준 실무값은 이렇다.

> 템퍼러처는 **코딩에 좀 빡빡하라고 0.4** 주고, top_p는 일반적으로 **0.95**, top_k는 **20개는 너무 빡빡하고 보통 권장 50에서 60개** 정도거든요. repeat_penalty는 안 줘. 근데 **모델이 작아 가지고 리즈닝 루프에 자주 빠지는 것 같으면** repeat_penalty를 주면 되고.

값 자체는 모델·서버마다 바뀐다. 기억할 것은 **repeat_penalty가 기본값이 아니라 증상에 대응하는 처방**이라는 구조다.

모달리티는 이름으로 알 수 없다.

> 똑같은 모델이라도 **우리가 적재한 모델이 모달리티를 제거한 모델일 수 있어요.** 얼마든지.

양자화·변환 과정에서 비전 부분이 빠진 배포본이 흔하므로 **등록할 때 사람이 지정**한다.

## 필수 지식 (HOW) — ③ 프리셋: 파라미터를 누가 소유하나

이 구조의 핵심이다.

> 같은 모델이라도, **같은 모델 식별자라도 컨텍스트나 템퍼러처가 다를 수도 있잖아.** 템퍼러처를 1.0짜리 쓰고 싶어. 이러면 얘 따로 저장하는 거야. 근데 **이름이 같아 가지고 안 되잖아요.** **이름을 좀 다르게 해서 여러 개 추가해서 프리셋을 미리 만드는** 거지.

표면적 이유는 "같은 모델을 용도별로 쓰기"다. 하지만 더 중요한 이유는 **통제**다.

파라미터를 요청 시점에 클라이언트가 보내게 하면, 조직별로 모델을 묶어 둔 의미가 절반 사라진다 — 어느 모델을 부를지는 통제되지만 **어떻게 부를지**는 통제 밖이다. temperature와 컨텍스트 크기는 품질뿐 아니라 **비용**과 안전성에 직결된다.

그래서 등록 단위가 "모델"이 아니라 **"모델 + 파라미터 조합"**이고, 서버가 프리셋 단위로 내려준다. 사용자는 파라미터를 고르는 게 아니라 **프리셋을 고른다** — 선택의 자유는 남고 경계는 관리자가 정한다.

부수 효과로 **이름이 실질적인 키**가 된다. modelId를 키로 잡으면 같은 모델의 두 번째 프리셋을 만들 수 없다.

## 필수 지식 (HOW) — ④ 시연에서 실제로 걸린 함정

엔드포인트 URL에 `localhost`를 넣었는데 연결이 실패했다.

> **Docker에서 돌고 있는 서비스의 `localhost`는 Docker 컨테이너 자신이죠.** 그래서 보통 `localhost`라고 쓰시면 안 됩니다.

관리 서버는 컨테이너 안에 있고 LM Studio는 호스트에서 돈다. 진단 신호가 특징적이다 — **연결은 되는 것 같은데 요청이 상대에게 도착하지 않는다.**

이 함정이 잘 걸리는 이유는 **개발 중에는 맞았다**는 점이다. 컨테이너에 넣기 전 로컬에서 돌릴 때 `localhost`가 정답이었으므로 설정이 그대로 남아 **배포 후에만 깨진다.**

## 이 지식이 판단에 쓰이는 자리

- **"모델 라우터를 만들라"를 받았을 때**: 권한 축인지 예산 축인지 먼저 가른다. 요구가 "토큰 소진 시 전환"이면 조직별 할당으로는 답이 안 된다.
- **추론 서버를 붙일 때**: OpenAI 호환이면 `/v1/models` 자동 조회 + 수동 폴백.
- **파라미터를 다룰 때**: 클라이언트가 보내게 하지 않는다. 다른 값이 필요하면 프리셋을 하나 더 만드는 것이 정상 경로다.
- **컨테이너에서 외부를 호출할 때**: `localhost`를 쓰지 않는다. 개발 중엔 통했다는 사실이 함정이다.

### ⚠️ 암기 필수

- [ ] **계획의 `개인별`과 구현의 `조직별`은 다른 축이다** — 전자는 **예산**(토큰 소진 시 전환, 2강이 핵심이라 부른 것), 후자는 **접근 권한**. 3강은 권한 축만 만들었다.
- [ ] **프리셋 = 모델 식별자 + 파라미터 조합, 이름이 키.** 파라미터를 클라이언트가 보내게 하면 **"어떻게 부를지"가 통제 밖으로 나가** 조직별 통제가 절반 무너진다.
- [ ] **등록 계층: 엔드포인트(API 형식·인증) → 모델 → 프리셋.** 목록은 `/v1/models` 자동 조회, 실패 시 수동 폴백.
- [ ] **모달리티는 이름으로 알 수 없다** — 적재된 배포본에서 제거될 수 있어 등록 시 지정한다.
- [ ] **repeat_penalty는 기본값이 아니라 증상(작은 모델의 리즈닝 루프)에 대응하는 처방**이다. 리즈닝 옵션을 끄는 선택지도 있다.
- [ ] **Docker 안의 `localhost`는 컨테이너 자신**이다. 개발 중엔 통했기 때문에 배포 후에만 깨진다.
