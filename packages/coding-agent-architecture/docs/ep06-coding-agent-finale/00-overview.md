# 06. 마지막 강의 — 이벤트 소싱 에이전트를 운영 가능한 구조로 만들기

> 원천 영상: [코딩에이전트 만들기 #6(끝)](https://www.youtube.com/live/vMXq7J0zeU0) · 뉴런데브 · 2026-09-01 · 약 95분

## 학습 목표

- 이벤트 소싱 기반 코딩 에이전트에서 워커·브로커·클라이언트의 경계를 설명한다.
- 프리픽스 캐시와 KV 캐시를 로그·메모리 산수로 진단한다.
- AI에게 구현을 맡길 때 결과물이 아니라 계속 수정 가능한 구조를 평가한다.

## 이 회차의 범위

20~38분의 특정 로컬 모델·하드웨어 리뷰는 시점 의존적인 나열이라 본문에서 제외했다. 나머지 구간은 다음 세 질문으로 묶인다.

1. 이벤트로 연결된 짧은 워커는 왜 확장되는가?
2. 빠르게 보이는 모델이 실제 긴 세션에서도 빠른지 어떻게 판별하는가?
3. AI가 코드를 작성해도 설계·용어·리팩토링 책임은 왜 사람에게 남는가?
