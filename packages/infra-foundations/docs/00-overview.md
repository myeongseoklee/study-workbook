# 배포를 이해하는 인프라 기초 — 처음 배우는 사람을 위한 교재

## 독자와 선수 지식

**컴퓨터공학과 1학년 신입생도 따라갈 수 있는 설명**을 목표로 한다. 브라우저를 사용해 본 경험과 사칙연산만 가정하며, 프로그래밍·운영체제·네트워크·DB·AWS 용어는 본문에서 풀어 쓴다.

선수 지식을 적게 가정하는 것과 내용의 깊이를 얕게 제한하는 것은 다르다. 정의와 필요성을 배운 뒤 실제 작동 주체·데이터·중간 상태를 따라가고, 실패 시 어느 과정이 달라지는지까지 다룬다. 처음 보는 전문 용어를 외워 다음으로 넘기는 방식으로 읽지 않는다.

일반적인 컴퓨터공학 전체 과정을 대신하는 책은 아니다. 프로그램을 실행하고 네트워크로 주문을 받으며, 데이터를 남기고 앱을 바꾸는 데 필요한 기초를 연결한다.

## 이 교재가 따라가는 한 가지 상황

작은 문구점의 주문 서비스를 만든다. 처음에는 컴퓨터 한 대에서 시작한다. 손님이 다른 컴퓨터로 접속하고, 주문을 저장하고, 손님이 늘면 앱을 여러 개로 나눈다. 실행 중인 앱을 새 버전으로 교체하고 이상을 관찰한 뒤, 마지막에 그 역할들을 AWS 이름으로 읽는다.

본문의 수량·가격·시간은 모두 설명용 가정이다. 실제 운영 시스템의 구성이나 성능을 측정한 자료가 아니다.

## 읽는 방법

각 장은 문제 상황에서 시작한다. 개념의 정의와 도입 이유를 읽은 뒤 **누가, 어디에서, 어떤 정보를 보고, 어떤 상태를 바꾸는지** 따라간다. What·Why·How는 핵심 설명으로, Who·Where·When은 실제 주체와 위치·사용 시점으로 연결한다.

예를 들어 04장의 번호는 SYN·ACK 이름 암기가 아니라 다음 번호를 직접 계산하는 데 쓰고, 09장의 실패 시점은 어떤 변경이 확정됐는지 판단하는 데 쓴다. 가정을 하나 바꾸었을 때 다음 단계가 어떻게 달라지는지 말할 수 있어야 한다.

한 장을 읽은 뒤 본문을 덮고 자가 진단에 답한다. 접힌 답은 스스로 설명한 다음 펼친다. 답변이 안 나오면 단어를 외우기보다 예제의 중간 상태를 다시 따라간다.

시간은 독자마다 다르다. 처음에는 장당 40~90분을 읽기·예제 재구성의 계획으로 잡아볼 수 있지만 저자의 추정이며 학습 효과를 측정한 값은 아니다. 이해가 끊기는 부분을 남긴 채 진도 수만 늘리지 않는다.

SQL과 HTTP 예시는 **형식과 원리를 읽는 자료**다. DB나 서버를 설치할 필요는 없다. 실제 명령 관찰은 워크북의 별도 과제에 모았다.

## 학습 후 확인할 수 있는 것

- [ ] 저장된 프로그램과 실행 중 상태, 오래 보관할 데이터를 구분한다.
- [ ] 이름 조회부터 주소·연결·보호·업무 요청까지 누가 무엇을 하는지 설명한다.
- [ ] 재고와 주문의 중간 실패·동시 변경을 예제로 재구성한다.
- [ ] 서버 수를 늘리거나 앱을 교체할 때 상태와 진행 중 요청을 어떻게 다룰지 설명한다.
- [ ] 실제 기록을 읽어 사용자 증상과 원인 가설을 구분한다.
- [ ] AWS 서비스를 실행·통신·저장·권한·관측의 역할에 연결한다.

## 부록과 연습

[90 암기 카드](90-must-memorize.md)는 18개의 핵심 관계를 복습하는 자료다. 모든 용어를 암기 대상으로 삼지는 않는다. 카드가 본문의 작동 과정 설명을 대신하지도 않는다.

[91 용어 해설집](91-glossary.md)은 앞에서 만난 개념을 어디서 배웠는지 찾는 길잡이다. 본문을 처음 이해하려고 사전을 계속 오가게 만드는 구성을 피했다.

[워크북 문제](../workbook/92-workbook.md)는 회수 18문항, 판단 8문항, 관찰·재현 4과제다. [자가 채점 해설](../workbook/93-solutions.md)은 문항별 필수 근거·답의 예·오개념 교정으로 연결한다. [힌트 색인](../workbook/94-hints.md)에서 필요한 단계만 따로 열 수 있다. 각 장의 연결 문항과 위 표를 함께 사용한다. 코딩 자동 판정 과제는 없으며 관찰과 설계 결과는 명시된 성공 기준으로 확인한다. 주 문항 30개를 유지하고 일부 문항에 조건을 바꾼 후속 복습 4개를 붙였다. 처음 답·도움 사용·나중의 독립 확인을 나눠 기록하며, 실제로 풀기 전 상태는 비워 둔다.

풀이는 레포 루트 `README.md` 규약 4의 별도 worktree에서 한다. 개인 진도와 오답은 `.study-log/`에서 관리한다. 새 교재의 등록은 학습 완료 표시와 다르다.
