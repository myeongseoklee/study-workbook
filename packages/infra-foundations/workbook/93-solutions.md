# 정답과 자가 채점 — 인프라 원리

먼저 [문제](92-workbook.md)를 풀고, 도움을 원하면 [힌트 색인](94-hints.md)을 연다. 아래의 문항별 링크에서 필수 기준·답의 예·오개념 교정·본문 복습 위치를 확인한다.

## 채점과 재시도 방법

자기 답에서 각 필수 기준에 해당하는 근거를 표시한다. 표현과 설명 순서는 달라도 된다. 열린 판단은 가정을 밝혀 같은 요구를 만족하면 인정한다. 근거가 모호하면 답이 맞았다고 추정하지 말고 미확인 부분을 남긴다.

| 기록 | 사용 기준 |
|---|---|
| 미확인 | 아직 답을 쓰지 않았거나 실제 관찰·근거를 확인하지 못함 |
| 다시 학습 | 필수 근거에 오류·누락이 있어 해당 본문으로 돌아감 |
| 도움받아 풀이 | 힌트·본문·해설을 본 뒤 기준을 충족함 |
| 독립 확인 | 도움 없이 쓴 답에서 필수 근거를 확인함 |

해설을 읽은 직후 따라 쓴 답은 독립 확인이 아니다. 몇 문제 뒤나 다음 학습 시간에 자료를 덮고 다시 풀어 본다. 일부 문항의 후속 복습도 별도로 대조한다. 이 기록은 해당 문항·조건의 수행이며 전체 숙달이나 자동 테스트 통과를 뜻하지 않는다.
